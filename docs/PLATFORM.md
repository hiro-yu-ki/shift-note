# シフトノート運営者画面（1.4.0）

公開入口：`https://shift-note.yuki-nova.workers.dev/platform`

この画面はシフトノートの運営者だけが使います。加盟店の契約、専用環境、請求・入金を管理します。従業員の勤務や時給は加盟店別のDBに保存し、この運営画面には表示しません。

## 初回設定

1. 公開サーバーを `scripts/start-cloudflare-preview.ps1` で起動します。初回設定キーは運営PCの `%LOCALAPPDATA%\ShiftNote\cloudflare-preview\platform-setup-token.txt` に作られます。内容を公開しないでください。
2. `/platform` を開き、12文字以上の運営者パスワードと初回設定キーを入力します。店舗の管理者パスワードとは別です。
3. 「請求元設定」に名称、住所、支払方法・振込先、該当する場合は適格請求書発行事業者の登録番号を入力します。税務上の記載内容は実際の取引に合わせて確認してください。

運営者パスワードは「請求元設定」の下から変更できます。変更すると他の端末のログインは無効になります。

## 加盟店を開始する

1. 「加盟店」→「加盟店を登録」で、URL用ID（英小文字・数字・ハイフン）、店舗名、契約名義、連絡先、プラン、月額料金、税率、期限、契約日を入力します。URL用IDは作成後変更できません。
2. 「専用環境を作成」を押すと、加盟店専用DBが作られ、管理画面・従業員画面・勤怠画面のURLが発行されます。3画面のリンクはこの画面からいつでも確認できます。
3. 表示された店舗管理者用の初回設定キーと管理画面URLを、加盟店の担当者へ安全な方法で伝えます。キーは再表示されません。担当者は管理画面でメールアドレスとキーを入力し、届いた30分有効のリンクからパスワードを設定します。次回から同じ加盟店URLでメールアドレスとパスワードを入力します。メール送信には運営PCのGmail送信設定が必要です。
4. 従業員には、その加盟店の従業員URLを渡します。本人のメール認証には店舗管理者側のGmail送信設定が必要です。勤怠画面は店舗管理者が端末登録して使用します。

URLは `https://shift-note.yuki-nova.workers.dev/s/<加盟店ID>/admin`、同じ末尾の `/employee`、`/clock` です。加盟店の利用状態を「停止中」「解約」にすると3画面へのアクセスを停止します。管理者のパスワードを失った場合は加盟店詳細で「管理者ログインを再設定」を使います。既存の管理者セッションと未使用の設定リンクが失効し、新しい初回設定キーが一度表示されます。加盟店ごとに認証DBを分けているため、別の加盟店で同じメールアドレスやパスワードが使われてもログイン先やセッションは混ざりません。

## 手動請求と入金

「請求・入金」で加盟店と対象月を選び、下書きを作ります。契約料金・税率・請求先・請求元・支払案内をその時点の値として保存します。同じ加盟店・対象月の重複請求書は作成できません。内容を確認して「発行」を押した後、請求書を開いてブラウザーから印刷またはPDF保存し、運営者が加盟店へ渡します。アプリから自動送信・決済はしません。

振込を確認したら入金額、入金日、照合番号を記録します。分割入金も可能です。誤記録は理由付きで訂正し、元の記録は履歴に残します。未収額と期限超過額は概要に表示されます。請求元や契約料金の後日の変更は発行済み請求書に反映されません。

## 保全と運用上の境界

運営者DBは `platform.db`、従来の単一店舗DBは `shift.db`、加盟店DBは `tenants/<内部ID>/shift.db` です。すべて運営PCの `%LOCALAPPDATA%\ShiftNote\cloudflare-preview` にあります。DBと秘密値をGitHubや加盟店へ配布しないでください。加盟店一覧はCSVで出力できますが、請求情報を含むため取り扱いに注意してください。

バックアップ先に新しいフォルダーを指定して、次のようにオンライン整合性検査付きバックアップを作れます。サーバー起動と同じPowerShell環境では環境変数をそのまま使えます。別のPowerShellから実行する場合は `--platform-db`、`--legacy-db`、`--tenant-root` に実ファイルの場所を渡します。

```powershell
.\.venv64\Scripts\python.exe scripts/backup_suite.py 'D:\ShiftNoteBackups\2026-09-29' --platform-db "$env:LOCALAPPDATA\ShiftNote\cloudflare-preview\platform.db" --legacy-db "$env:LOCALAPPDATA\ShiftNote\cloudflare-preview\shift.db" --tenant-root "$env:LOCALAPPDATA\ShiftNote\cloudflare-preview\tenants"
```

バックアップは運営者DBと各店舗DBのそれぞれ一貫したコピーです。複数DBをまたぐ同一瞬間のスナップショットではありません。定期的にPC外へ安全に保管し、復元を練習してください。現在の無料構成は運営PC・アプリ・Tunnelが常時起動している間だけ利用できます。複数台サーバーでの同時運用や可用性保証は含みません。運営者は単一パスワードで、担当者別権限や決済連携は未実装です。
