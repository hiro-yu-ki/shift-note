従業員を登録し、シフトを配布する

管理画面メール登録シフト作成従業員向け手順

この手順でできること

従業員ごとの認証と契約を管理し、提出希望からシフト案を作成・確認・確定します。従業員へ配るURLは全員共通ですが、表示される情報はログインした本人のものです。

始める前に

  • 公開環境とメール送信の設定を済ませます。運営者向けの手順は docs/PLATFORM.md にあります。
  • 加盟店専用の管理者URL（末尾 /admin）を開きます。初回は管理者のメールアドレスと運営者から渡された初回設定キーを入力します。届いたリンクを30分以内に開き、10文字以上のパスワードを登録します。
  • 次回からは同じ加盟店URLでメールアドレスとパスワードを入力します。別の加盟店にはその加盟店のURLを使います。
  • 既存データがある場合は、更新前にバックアップを取得します。公開用パッケージには店舗データや認証情報は含まれていません。

1. スタッフのメール認証を登録する

  1. 「スタッフ」でスタッフ本人の情報を登録します。氏名・担当可能な役割・契約時給・勤務条件を確認します。
  2. 「従業員のログイン管理」で対象スタッフを選び、本人が受信できるメールアドレスを入力します。
  3. 「メールアドレスを登録・変更」を押します。一つのメールアドレスを複数人に使うことはできません。
  4. 「配布URLをコピー」を押し、従業員へ伝えます。従業員向け手順書も一緒に配布してください。登録操作だけではメールは送信されません。
  5. 従業員にログインしてもらい、自分の名前が表示されることを確認します。

アドレス変更時は以前のログインと未使用の確認コードが失効します。退職者は「利用停止」、またはスタッフの無効化を行ってください。利用停止後もシフト・給与の履歴は残ります。

2. 希望を集め、シフトを作成する

  1. 「店舗設定」で営業時間・入力単位・休憩条件を設定します。必要な役割は「必要人数・役割」で追加し、担当を許可するスタッフに割り当てます。
  2. 「期間を作成」で開始日・終了日・締切を設定します。「必要人数・役割」で時間帯ごとの必要人数を入力します。
  3. 「希望の提出状況」で提出済みかを確認します。基本曜日を登録しても、本人の希望提出の代わりにはなりません。
  4. 個別の勤務条件文を入力した場合は、読み取り結果を確認して適用します。理解できない文章はエラーになります。「備考」と任意の記録項目は自動作成に反映されません。
  5. 「シフト案を作成」を押し、事前確認後に3案を作成します。進捗が表示されます。同じ条件で再作成すると既存案を再利用します。
  6. 不足人数・役割・実働時間・人件費・休憩を比較します。必要なら勤務を押して調整し、「再検証」を押します。
  7. 全体を確認してから「この案を確定する」を押し、確定者名を入力します。従業員の「確定シフト」に反映されます。

提出時間外には勤務を入れられません。人数不足と重大違反は別です。重大違反は確定を止めますが、人数不足だけなら確認して確定できます。自動案が店舗にとって十分か、必ず人が確認してください。

カレンダーと必要人数の見方

「週・日カレンダー」は日付が縦、時間が横です。名前にマウスを重ねると勤務・担当・休憩が分かります。時間枠を押し、対象の名前を選ぶと編集できます。「表示の詳細設定」で表示時間数や時刻・役割の表示を変更できます。「一日の配置」には、その日勤務する人だけが表示されます。

「必要人数・役割」は月曜〜日曜の各ページで設定します。「特定日」で日付を選ぶと例外を設定できます。特定日の設定は、その曜日の設定全体を置き換えます。

3. 契約と勤務時間を確認する

雇用区分に加え、必ず勤務する契約がある人は曜日・開始・終了を「固定勤務」に登録します。雇用区分だけで勤務を自動的に決めることはありません。固定勤務も本人の提出希望内に限ります。矛盾したときは本人と確認し、希望または合意した契約条件を直してください。除外日は固定勤務の義務だけを外します。休む場合は本人の希望も勤務不可にしてください。

  1. 「スタッフ」で時給・交通費・締日・支払日を登録します。他の従業員から本人以外の契約は見えません。
  2. 「シフト案」の「勤務時間と人件費」で、勤務時間の偏りと合計人件費を確認します。未登録の時給は「未計算」です。
  3. 確定後に修正するときは、対象期間を再編集に戻して変更・再確定します。その間、従業員には確定勤務が表示されなくなります。

給与見込みは正式な給与計算ではありません。古い確定案には休憩を自動挿入しません。必要なら再編集して作り直します。

4. 変更申請と勤怠

  1. 「勤怠・変更申請」で端末登録リンクを作り、店舗の共用端末で一度だけ開きます。次回からは固定URL /clock で使えます。リンクを知る人は名前を選んで打刻できるため、店舗内だけで扱ってください。登録リンクは1台の登録で無効になりますが、登録済み端末は使い続けられます。端末を失った場合は管理画面から利用停止します。
  2. 従業員は本日の確定勤務から名前を選んで出勤し、退勤時は出勤中の一覧から名前を選びます。
  3. 退勤後は実際の休憩時間を確認し、修正理由を入力して保存します。予定休憩を自動的に控除しません。
  4. 変更相談には回答を記入します。回答だけでは確定シフトは変わらないため、必要なら再編集・再確定します。
  5. 人件費の実績概算と、今後の確定勤務を含む見込みを比較します。税・保険・割増賃金・控除は含みません。

困ったとき

表示・状況対応
メール認証が未設定送信元の設定手順を確認します。設定前の画面確認には、ログイン管理の「選択した従業員の画面を確認」を使えます（閲覧のみ）。
同じメールが登録済みスタッフを取り違えていないか確認します。共有メールは使わないでください。
他の画面で更新された再読み込みし、最新の提出状況でやり直します。
0時間のスタッフがいる理由欄と提出日数、最短勤務、担当資格、勤務上限、需要との重なりを確認します。
作成に失敗した以前の案は保持されます。条件や起動環境を確認し、再度作成します。

運用の習慣

毎日のバックアップ、復元確認、退職者の利用停止を担当者の作業として決めてください。管理者パスワードと初回設定キーは従業員に配布しません。共用端末では利用後にログアウトします。
