希望を提出し、確定シフトを確認する

従業員ログインログイン希望の提出確定シフト

この手順でできること

自分のメールアドレスでログインし、カレンダーから希望を提出します。確定後は、自分の勤務・休憩・給与見込みを確認できます。

始める前に

  • 管理者に、本人が受信できるメールアドレスを登録してもらいます。
  • 管理者から配布された、末尾が /employee のURLを開きます。スマートフォンでも使えます。
  • メールを受信できる状態にします。確認コードを他人に渡さないでください。

1. ログインする

  1. 登録したメールアドレスを入力し、「確認コードを送る」を押します。
  2. 届いたメールの8桁の数字を、元の画面の「確認コード」に入力します。有効期限は10分です。
  3. 「ログイン」を押します。画面に自分の名前が出ていることを確認します。
  4. 上部の「対象期間」から、希望を提出する期間を選びます。

届かないときは迷惑メールを確認してください。再送は60秒以上あけます。新しいコードを発行すると古いコードは使えません。届かない状態が続くときは管理者に登録アドレスを確認してください。

2. シフト希望を提出する

  1. 「希望を申請」を開き、日付を押します。
  2. 勤務できる時間を入力します。画面に表示される15分・30分・1時間の単位で入力してください。
  3. 「勤務可能」「できれば入りたい」「勤務不可」を選びます。空欄の時間は勤務できない時間として扱われます。
  4. 必要な日付を入力します。基本の曜日が登録されている場合は、未入力日への取り込みも使えます。契約上の固定勤務も、未入力日に取り込めます。既に入力した日付は変更されません。取り込みだけでは提出されません。
  5. 入力内容を確認し、提出ボタンを押します。一時保存だけでは提出済みになりません。「提出済み」の表示を確認してください。

提出後も締切までは修正・再提出できます。締切後の変更は管理者へ相談してください。勤務可能な時間を出しても、そのすべてに勤務が入るとは限りません。

3. 確定シフトと給与見込みを確認する

  1. 「確定シフト」を押します。管理者が確定するまでは勤務は表示されません。
  2. 勤務のある日付を押し、開始・終了・担当・休憩時刻を確認します。
  3. 勤務時間と次回給与の見込みを確認します。休憩は給与対象の勤務時間に含まれません。
  4. 共用端末を使った場合は「ログアウト」を押します。次回は新しい確認コードでログインします。

給与は登録契約に基づく控除前の概算です。税・保険・割増賃金・実際の出退勤による差は含みません。「時給未登録」の場合は管理者へ確認してください。

4. 勤務日・変更相談

  1. 「勤務日・変更相談」には、これからの確定勤務が日付順に並びます。
  2. 変更したい勤務の「変更を相談」を押し、理由を書きます。勤務時間を変えれば働ける場合は、対応可能な開始・終了時刻も入力します。
  3. 「相談の状況」で管理者の回答を確認します。送信だけでは確定シフトは変わりません。変更が決まったら更新された確定シフトを確認します。

5. 勤務実績・給与

店舗の打刻画面で自分の名前を選んで出勤・退勤します。「勤務実績・給与」で打刻時刻、実働、給与の概算を確認できます。休憩は管理者が実績を確認して登録します。間違いがあれば管理者に修正を依頼してください。

困ったとき

表示・状況対応
メール認証の準備中管理者によるメール送信設定が必要です。
コードが一致しない・期限切れ最新のメールを確認し、必要なら再送します。5回失敗するとそのコードは使えません。
ログインし直すよう表示された24時間の期限、メール変更、利用停止の可能性があります。再ログインできなければ管理者に相談します。
対象期間がない管理者の期間登録を待ちます。
